Resumo simples do projeto

Tech Challenge Fase 4 · o que já está pronto e o que falta. Atualizado em 25/10/2026.

Já está pronto FEITO

Treino do modeloO código treina dois modelos (XGBoost e regressão logística). Mas o arquivo do modelo não existe no seu computador, porque falta o CSV do Kaggle.
Simulação de driftOs dados de produção foram alterados de propósito (idade, crédito, escores).
Relatório de driftO relatório do Evidently e a tabela com PSI/KS já foram gerados. 17 features driftaram em ao menos um teste e 7 pelo PSI.
API e painel básicoA API mede requisições, erros, tempo de resposta e predições. Existe um painel no Grafana com isso e o MLflow está no Docker.

Falta fazer PENDENTE

Etapa 1 · vale 25%
  • O contrato de dados com as regras de qualidade não existe (o arquivo está vazio).
  • Faltam pelo menos 3 regras, como idade maior que 18, renda sem nulos e sem duplicados.
  • Falta mostrar um lote ruim sendo barrado.
Etapa 2 · vale 25%
  • Faltam as predições do modelo nos dados de produção.
  • Falta comparar os dados de treino com os de produção. Hoje o relatório compara só o período 1 com o período 2.
Etapa 3 · vale 20% · foco agora
  • Métricas do pipeline: se cada etapa deu certo, quanto tempo levou e quantas linhas processou.
  • Mandar os resultados do drift para o painel.
  • Alertas.
  • Logs organizados.
  • Registrar cada execução no MLflow.
  • Um painel novo de saúde do pipeline.
Etapa 4 · vale 15%
  • Escrever a parte de LGPD no README: dados pessoais, base legal, retenção e análise causal.
Vídeo · vale 15%
  • Gravar o vídeo de 5 minutos.
